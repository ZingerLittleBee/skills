# Writing X Chinese Briefs

## Overview

Turn English source material into short Chinese X copy with one clear fact and one clear take. If the source is thin, do not inflate it into a thread, compress it into a quote-post line.

## Core Rule

Default to **one sentence**. Use **two sentences only** when the first gives the fact and the second gives the take.

Good short X copy is not a summary. It is a compressed judgment.

## Workflow

1. Identify the source strength:
   - **Thin**: one policy change, product note, rumor, or single fact.
   - **Thick**: multiple facts, data, conflict, or consequences.
2. For thin sources, write a quote-post take, not a standalone explainer.
3. Keep only:
   - the concrete fact;
   - the human consequence;
   - one memorable judgment.
4. Remove setup, caveats, trend paragraphs, and “why this matters” filler unless the user asks for a longer version.

## Output Shapes

| Source | Shape | Example |
|---|---|---|
| Thin | one punch line | `匿名 AI 时代快结束了。` |
| Thin with useful fact | fact + take | `Claude 之后可能要求 Free / Pro / Max 用户验证年龄或身份。匿名 AI 时代快结束了。` |
| Thick | 2 short lines | `OpenAI 这次不是小修小补，而是在改开发者成本结构。小团队会舒服一点，高并发产品得重新算账。` |

## Voice

- Write in Simplified Chinese.
- Prefer plain spoken Chinese over report language.
- Sound like a person reacting to the news, not a newsletter.
- Use strong but defensible claims.
- If the source is weak, say less. Do not fake depth.

## Cut List

Remove phrases like:

- `这次更新最值得关注的是`
- `从更大的趋势来看`
- `这不是某一家公司的问题`
- `AI 产品正在进入一个新阶段`
- `对用户来说可能会带来一些影响`

They usually smell like filler unless the line is genuinely sharp.

## Common Mistakes

- Explaining the algorithm instead of writing the post.
- Turning a one-fact source into a five-paragraph take.
- Using big abstractions when a concrete user pain is available.
- Adding links, sources, or caveats inside the main post when the user wants a quote-post line.
- Writing a “balanced” paragraph that has no position.

## Quick Check

Before replying, ask:

- Can this be shorter?
- Is there exactly one fact and one take?
- Would this work as a quote-post without extra context?
- Is the best line first?
