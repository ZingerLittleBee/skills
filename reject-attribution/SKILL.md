# Reject attribution

Install this guard in the current repo. Copy the files in this skill; do not
rewrite the matchers. Regex lives only in
[`scripts/attribution-lib.sh`](scripts/attribution-lib.sh).

Do not add Husky, lint-staged, or the pre-commit framework. Lefthook is the
only hook runner. Do not put tests, `tsc`, or clippy in `pre-commit`.

## Rules

Three matchers, humans and agents treated the same:

1. `Co-authored-by:` at line start (case-insensitive).
2. `🤖 Generated`, `Assisted-by:`, or `Generated`/`Made` `with`/`by` plus a
   known agent name.
3. Any email address. `icon@2x.png` and `lodash@4.17.21` are not emails.

| Surface | Who | Matchers |
|---|---|---|
| Lefthook `commit-msg` | local `git commit` | 1 + 2 + 3 |
| CI each commit `base..head` | pull_request | 1 + 2 + 3 |
| CI PR title + body | pull_request, including `edited` | 2 + 3 |

`--no-verify` and `LEFTHOOK=0` skip only the local hook. CI still fails.

## 1. Inspect

Read `.github/workflows/`, `lefthook.yml`, `package.json` / lockfiles,
`.gitignore`, `README.md` or `CONTRIBUTING.md`, and `AGENTS.md` / `CLAUDE.md`
/ `.cursor/rules` if they exist.

Merge into what is already there. Do not add a second hook runner or a
second attribution workflow.

Done when you know: whether Lefthook exists, how JS deps are installed (or
that there is no Node), and which lightweight `runs-on` existing workflows
use.

## 2. Copy scripts and CI

Copy these four files to `.github/scripts/` in the target repo, keep names,
keep `+x` on the `check-*.sh` files:

- `scripts/attribution-lib.sh`
- `scripts/check-co-authors.sh`
- `scripts/check-commit-msg.sh`
- `scripts/check-pr-attribution.sh`

Copy [`references/check-commit-attribution.yml`](references/check-commit-attribution.yml)
to `.github/workflows/check-commit-attribution.yml`.

Set `runs-on` to the same value as another lightweight job in this repo. If
there is none, leave `ubuntu-latest`.

`fetch-depth: 0` is required. Pass PR title and body through `env`; never
interpolate `${{ github.event.pull_request.body }}` into the `run:` string.
Null/empty body must not crash.

## 3. Lefthook

If `lefthook.yml` exists, append only the `commit-msg` block from
[`references/lefthook.yml`](references/lefthook.yml). Leave existing
`pre-commit` jobs untouched.

If it does not exist, copy that file as `lefthook.yml`.

Install:

- **`package.json` present:** add `lefthook` as a devDependency with the
  repo's package manager (`bun` / `pnpm` / `npm` / `yarn`, from the lockfile).
  Add `lefthook install` to `prepare`. If `prepare` already exists, append;
  do not drop other commands.
- **No Node:** do not add a `package.json`. Document
  `brew install lefthook && lefthook install` in README or CONTRIBUTING.

Add `lefthook-local.yml` to `.gitignore` if it is not already ignored.

Run `lefthook install` so the `commit-msg` hook is present. There must be no
pre-commit hook that runs tests.

## 4. Docs

In README or CONTRIBUTING, add a short section:

- Lefthook blocks `Co-authored-by`, Generated by/with, `🤖 Generated`,
  `Assisted-by`, and any email on `git commit`.
- CI scans every commit on the PR and the PR title/description.
- `--no-verify` / `LEFTHOOK=0` will not pass CI.
- Fix: `git rebase -i <base-sha>`, drop the matching lines, force-push.
- Mark the GitHub check **Check commit attribution** as required in branch
  protection. The workflow cannot enable that.

If `AGENTS.md`, `CLAUDE.md`, or `.cursor/rules` exists, add:

Write commit messages and PR titles/bodies without attribution trailers or
email addresses. Never add `Co-authored-by`, `Generated by`, `Generated with`,
`🤖 Generated`, `Assisted-by`, or any email address.

## 5. Verify

```bash
bash -n .github/scripts/attribution-lib.sh
bash -n .github/scripts/check-co-authors.sh
bash -n .github/scripts/check-commit-msg.sh
bash -n .github/scripts/check-pr-attribution.sh
lefthook validate
```

Then, using a temp message file and `PR_TITLE` / `PR_BODY`:

Must fail:

- `Co-authored-by: Alice <alice@company.com>`
- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- `🤖 Generated with Claude Code`
- `alice@company.com` in a commit message
- `alice@company.com` in a PR body
- empty/`unset` PR body must not crash; it must pass unless other rules hit

Must pass:

- a plain conventional commit
- `This change can generate reports.`
- `Updated icon@2x.png`

Also run `lefthook run commit-msg <file>` on a clean message (pass) and on
an email (fail).

Done when `bash -n` is clean, the cases above match, Lefthook has no
pre-commit heavy checks, and Husky was not added.

## 6. Handoff

List the files added or changed. Tell the user to require the GitHub check
**Check commit attribution**. The workflow cannot set that.
