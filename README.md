# skills

Personal collection of [agent skills](https://skills.sh/) for Claude Code and the
open agent-skills ecosystem. Each top-level directory is one skill, except
[`agent-profile/`](agent-profile/) which holds the shared agent profile and
[`goals/`](goals/) which holds reference-only Codex goal drafts (see below).

## Install

Install a single skill with the Skills CLI:

```bash
npx skills add ZingerLittleBee/skills@<skill-name>
```

Add `-g` to install globally (user-level) and `-y` to skip confirmation prompts.

## Skills

| Skill | Description |
|---|---|
| [`design-parity`](design-parity/) | Measure how faithfully an app, native or web, reproduces its HTML or React design mockup and interactions: tokens, layout arithmetic and clamps, hit-tested interactions, and screenshots against references, each finding with expected, actual, and method. Runs on a per-project `.design-parity/project.md` profile. Invoke with `/design-parity [scope]`. |
| [`dispatch-tickets`](dispatch-tickets/) | Run a set of tracker tickets to completion in one session: a dispatcher main agent contracts the dependency graph's straight chains and layers them into waves, runs each wave of two or more chains in parallel as one [`herdr-fleet`](herdr-fleet/) round (one package per chain, a fresh implementer per ticket) when herdr is available, runs everything else serially through fresh implementer subagents, verifies each result, and closes tickets wave by wave. Invoke with `/dispatch-tickets #N #N …` or `parent=#N`; `mode=serial` skips the fleet. |
| [`publish-release`](publish-release/) | The release convention: unreleased work accumulates under CHANGELOG's `[Unreleased]` heading, and one `make publish` (options as make variables: `VERSION=`, `DRY_RUN=1`, `YES=1`) cuts it — renaming the section, updating each declared version file, regenerating the derived ones by command, tagging, and releasing via GitHub Actions or a local build. Prints the whole plan and asks before mutating anything. |
| [`herdr-fleet`](herdr-fleet/) | Run one round of parallel implementation across multiple CLI coding agents (claude, codex, grok, agy, droid, …) in herdr-managed git worktrees. Four roles (orchestrator, implementer, reviewer, scout) run on named model slots with fallback candidates: the orchestrator packages the backlog with scout reports, assigns each package a slot by difficulty, watches progress, grades fixed commits with cross-vendor reviewer agents that return structured verdicts, runs checks serially in shell panes, merges accepted packages onto one local branch, and removes only clean merged worktrees. Invoke with `/herdr-fleet`. |
| [`testloop`](testloop/) | Run a host-agnostic GUI test-fix loop through Herdr with a `gpt-6-astra` Codex tester using low reasoning: the current agent builds, installs, launches, judges, and fixes, while Codex drives web apps via `ego-browser` by default (configurable to `agent-browser`) and desktop/mobile apps via `@Computer-Use`. Requires a Herdr-managed pane. Invoke it explicitly with the host's skill syntax; an optional scope can narrow the run. |
| [`ui-research`](ui-research/) | Research how excellent products design and implement a piece of UI (visual references, motion, implementation, principles) and present an evidence-backed local HTML report with screenshots; greps the current repo before recommending anything. Triggers automatically on UI-research-shaped requests. |
| [`unslop`](unslop/) | Humanize English or Chinese prose when explicitly requested. Removes formulaic AI writing patterns while preserving facts, intent, technical language, quotations, and regional Chinese usage. |
| [`writing-x-zh-briefs`](writing-x-zh-briefs/) | Turn English X posts, AI news, product updates, or thin source material into concise Simplified Chinese X posts, quote-post takes, or one-to-two sentence commentary. |
| [`reject-attribution`](reject-attribution/) | Install CI and Lefthook checks that reject `Co-authored-by`, Generated by/with agent text, and any email in commit messages and PR title/body. Invoke with `/reject-attribution`. |

Install all of them on a new machine or VM (needs Node.js; no clone required):

```bash
curl -fsSL https://raw.githubusercontent.com/ZingerLittleBee/skills/main/install-skills.sh | bash
```

From a clone, run `./install-skills.sh`. Re-running updates every skill to its
latest upstream version. Skills are linked into a fixed agent list (Claude Code,
Codex, Amp, Cursor, and others); override it with `SKILLS_AGENTS`:

```bash
curl -fsSL https://raw.githubusercontent.com/ZingerLittleBee/skills/main/install-skills.sh | SKILLS_AGENTS="claude-code codex" bash
```

The list lives in [`install-skills.sh`](install-skills.sh); update it together with
this table.

## Agent profile

[`agent-profile/AGENTS.md`](agent-profile/AGENTS.md) is the user-level agent profile
shared across Claude Code, Codex, Amp, OpenCode, Droid, Grok, Delta, and Cursor. It is not a
skill; it is version-controlled here and wired into each tool by
[`./setup-agent-profile.sh`](setup-agent-profile.sh) (symlinks for most tools; a
generated always-apply `.mdc` for Cursor). On a new machine, clone this repo and
run that script; see [`agent-profile/README.md`](agent-profile/README.md) for details.

## Goals

[`goals/`](goals/) is a reference library for long-running Codex goal drafts. It
is not installed, loaded automatically, or exposed as a quick invocation. Open a
goal and copy its contents manually when needed; see
[`goals/README.md`](goals/README.md).
